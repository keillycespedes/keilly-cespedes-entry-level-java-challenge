# Testing Help

## Tests are required

### Standards
Use **JUnit** as the test framework and adhere to standard conventions.
`spring-boot-starter-test` is already on the test classpath, so MockMvc and
`@SpringBootTest` are available to you.

### Resources
This [Spring Web Test tutorial](https://spring.io/guides/gs/testing-web) and [JUnit 5 guide](https://www.baeldung.com/junit-5) could be useful resources!
